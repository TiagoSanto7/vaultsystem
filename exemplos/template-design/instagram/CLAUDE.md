# Posts do Vault System

Este projeto segue o template `design:instagram`. Antes de criar ou editar um post, leia `POSTS.md` e as notas em `docs/vs/`.
Responda em português. Comandos da CLI que aparecem no post são sempre em inglês.
Não invente tema, texto ou série de posts sem pedido: o conteúdo vem de quem pede; o template só define a forma.
Use só os tokens e componentes do pacote; nada de cor, fonte ou efeito fora deles.
