# Design system do Vault System (default)

Pacote base da identidade do Vault System: tokens de cor e tipografia, o símbolo
orbital, os componentes de botão e cartão e uma tela de exemplo montada com eles.

Aplicar num projeto:

```sh
vs add template design:default
```

Comece por `exemplo/index.html`. As regras e as orientações estão em `docs/vs/`.
