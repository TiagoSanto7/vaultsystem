# Azul orbital e Ubuntu

**Decisão:** o Vault System usa o azul `#0758ed` com neutros azulados e a fonte
Ubuntu, separando-se do verde do PetroVault, de onde o produto nasceu.

**Por quê:** o Vault System é a base independente; o PetroVault continua como a
aplicação da Petrovina. O azul e a órbita traduzem "conhecimento distribuído",
e a Ubuntu já era a fonte da interface herdada, o que evita retrabalho.

**Fora:** gradientes fortes, sombras pesadas e uma segunda cor de destaque.
