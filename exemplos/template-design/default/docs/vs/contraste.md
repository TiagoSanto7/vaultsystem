# Contraste e acessibilidade

- Texto sobre `--vs-azul` é sempre branco (`#ffffff`): contraste de 5,8:1.
- Nunca texto em `--vs-azul-claro` sobre papel branco: não passa de 3:1. O azul
  claro é para órbita, ilustração e foco, não para texto.
- Texto secundário (`--vs-tinta-suave`) só em 13 px ou mais.
- Todo elemento interativo tem foco visível (contorno de 3 px em azul-claro).
- Layout funciona a partir de 320 px de largura, com 16 px de margem lateral.
