# Uso da marca

1. O nome é sempre "Vault System", com as duas palavras em maiúscula. O comando
   do terminal é `vs` e o de abertura é `vaultsystem`, tudo junto.
2. A assinatura é "Conhecimento distribuído." (com ponto).
3. O símbolo não é recolorido, girado nem distorcido.
4. Azul de marca só para ação e destaque: nunca como fundo de página inteira.
5. Nada de outra fonte além de Ubuntu e da monoespaçada de código.
